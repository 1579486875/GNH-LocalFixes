## 3. 旧版本向下兼容（用户特别强调）

> 「尤其是从其他渠道下载的本地模组，有些人可能还用着旧版模组」

### 3.1 LocalFixes：22 个补丁 58 个 `<Operation>`，**全部有守卫**

守卫的三种合法形态：
1. 操作自带 `<success>Always</success>`
2. 外层 `<PatchOperationSequence>` 带 `success=Always`（向下传递）
3. 外层 `<PatchOperationFindMod>` / `<Test>` 容器

**扫描结果：无守卫的 0 个。**

**判据有效性验证**（造的假补丁）：
```
Bad.xml（无 success）   → 被正确报出 ✓
Good.xml（有 success）  → 未被误报 ✓
```

⇒ **目标模组的旧版/缺版时，补丁安静跳过，不刷红字** —— 这正是「向下兼容」的核心保证。

### 3.2 NMM 汉化：靠游戏自身的宽松行为

`DefInjected` 的键若指向不存在的 def，游戏会：
1. 打一条 `Found no <Type> named <defName>`（进 `loadErrors`）
2. **跳过该键**，不影响其它键
3. 最终汇总成**一行** `Translation data for language … has N errors`

⇒ **不影响功能**，只是日志多几条。这是平台行为，不是我们能改的。

**已经做的分离**：

| 层 | 键数 | 服务对象 |
|---|---|---|
| `Languages/ChineseSimplified (简体中文)/` | 11,780 | 1.6 的 `shark510.nuditymattersmoreopinions` |
| `v1.7/Languages/ChineseSimplified (简体中文)/` | 131,957 | 1.7 的 `dord.nuditymattersmore` |

两层**键集合完全不相交**，各自对自己的上游 0 悬空。
所以「装 1.6 老版」不会因为 1.7 的键而多报错。

## 4.1 ⑥ 人称：45% 不含「我」，但**这不是问题**

**扫描**：262,510 条正文（`opinionTexts.N` / `texts.N`）里，
**118,126 条（45.00%）不含「我」且长度 ≥12**。

**抽样 10 条**：

```
{PAWN_nameShort}的那对小小的{OBSERVED_partSpecificLabel}又紧又可爱，几乎是在求人捧一把。
一对精致的小{OBSERVED_partSpecificLabel}，光滑又紧实。小成这样反而有种说不出的吸引力。
那对小小的{OBSERVED_partSpecificLabel}不怎么显眼。
{PAWN_nameShort}的那对萎缩的微小{OBSERVED_partSpecificLabel}看着可怜，像没发育起来。
可怜巴巴的一点{OBSERVED_partSpecificLabel}。实在没法当回事。
```

**判定：全部是中文里极自然的「省略主语」**，不是第三人称错误。

两个理由：

| 理由 | 说明 |
|---|---|
| 1 | 提示词原文是「心情描述**通常**用第一人称」—— **「通常」不是硬性** |
| 2 | 中文里「*看着可怜*」「*实在没法当回事*」这种**心理判断句省略主语**比硬加「我」更自然。硬改成「我看到…我觉得…」反而会变成提示词第 27 行明确禁止的「逐字直译、生硬机翻感」 |

**没有发现真正的第三人称错误**（如「他很喜欢 X 的…」这种把观察者写成第三方的）。
