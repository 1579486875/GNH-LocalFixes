### 3.2 顺带修掉一处不该存在的改动

检查 `git status` 时发现 `MihoChildrenTextureFix/1.6/Patches/Baby_patch.xml`
显示「**86 增 86 删**」，但逐行内容完全相同。

查字节：

| | 大小 | CRLF | 裸 LF |
|---|---|---|---|
| 磁盘 | 5,483 | **86** | 0 |
| git HEAD | 5,397 | 0 | **86** |

**纯换行差异**（归一化后内容完全相同）。

而这个仓库的 `.gitattributes` 明确写着：

```
# 本仓库所有文件都保持原始字节，禁止 git 做任何换行转换。
# 为什么必须写这一条：
#   ① 本机 git 的 core.autocrlf = true（git for Windows 的默认设置）。
#      不在这里显式声明的话，git 每触碰一次工作区就会把 LF 换成 CRLF，
#      于是「仓库里的字节」和「部署进 Mods\ 的字节」不再是同一份 ——
#      任何按字节核对的做法（SHA256 / md5 比对）都会失去意义。
#   ② 本仓库的换行本来是**混的**……加 `* -text` 之后两边都保持原样。
* -text
```

**所以这个 CRLF 变更不该存在** —— 已 `git checkout` 回滚为 HEAD 的裸 LF 版本，
并确认回滚后 XML 仍可解析（5,397 B / CRLF 0 / 裸 LF 86）。

**根因推测**：某次工具写入（编辑器/Python 文本模式）把 LF 规范化成了 CRLF。
`* -text` 只阻止 **git** 做转换，阻止不了**写入工具**。
