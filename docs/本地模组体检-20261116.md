## 3. 已修：Doop 奶牛汉化补丁的两处裸尖括号

**文件**（1.6 副本，1.7 副本本来就好的）：

```
Languages\ChineseSimplified\DefInjected\HediffDef\CattleDefs.xml          line 9,  col 187
Languages\ChineseSimplified\DefInjected\MemeDef\IdeologyDefs.xml         line 110, col 83
```

**症状**：`XML 解析失败：not well-formed (invalid token)`

**根因**：`descriptionCached` 的值里写了 RimWorld 的富文本标签，但**没有转义**：

```xml
<CattleConditioning.descriptionCached>…正常运作。\n\n<i><color=#66E0E4FF>Human Cattle - Yet Another Milk Mod</color></i></…>
```

XML 解析器把 `<i>` / `<color=#…>` 当成元素开始标签 → 报错 → **整个文件不加载**，
这个 HediffDef 的中文全丢。

**修法**：只把**元素值内部**的那几个富文本标签转义（`<i>` → `&lt;i&gt;` 等）。
XML 解析后得到 `<i><color=#…>`，**RimWorld 的富文本仍然认得，显示效果不变**。
`<CattleConditioning.description>` 这些**真标签**一个没动。

**验证**：两个副本重新全量解析 —— **1.7 副本 43 个文件 / 1.6 副本 38 个文件，坏 0**。

## 4. 不改：153 个模组的 `supportedVersions` 不含 1.7

**事实**：把这 153 个模组逐个拿到当前 1.7 日志里搜（按模组名 / packageId / 目录名三种线索），结果是
**152 个零报错**，唯一有报错的是 `RJW_玩法_缇瓦莱特贞操科技`（2 条，**正是【54】修掉的那两条**）。

**但我不给它们加 `1.7` 声明**，理由三条：

| # | 理由 |
|---|---|
| 1 | **那是作者对兼容性的声明**。加了等于替作者宣布「这个模组在 1.7 可用」 |
| 2 | **零报错 ≠ 功能完好** —— 可能只是这一局没触发到出问题的路径 |
| 3 | **改了会在工坊更新时被覆盖**，玩家看到的状态会来回跳 |

> 这一条属于「**知道现状、但选择不动**」。如果用户希望「模组列表不再标不兼容」，
> 那是另一个需求 —— 需要逐个人工确认功能，不是批量改声明能解决的。

## 5. 假阳性：4 个「有 1.7 目录但没 LoadFolders」

| 模组 | 实际情况 |
|---|---|
| `RJW-Sar0-雪兔SA花花兔子服装扩展` | 根目录只有 `About` / `Textures`，没有 Defs |
| `雪兔坏女孩扩展` | 根 `Languages` 1 个文件、`1.7/Languages` 1 个文件，**不同名不冲突** |
| `sov.det.surrogatemech (GNH 1.7 分支)` | 根目录无 Defs |
| `sov.det.surrogatemech`（1.6 副本） | 同上 |

**反编译 `Verse.ModContentPack.InitLoadFolders()` 实证**（1.7.5011）：

```csharp
string text2 = Path.Combine(RootDir, VersionControl.CurrentVersionStringWithoutBuild);  // …/1.7
if (Directory.Exists(text2))
    foldersToLoadDescendingOrder.Add(text2);      // ← 有 1.7/ 就只加载 1.7/
else { …挑最高版本目录… }
… Add(Common); Add(RootDir);
```

⇒ **没有 `LoadFolders.xml` 时，引擎自动只加载「当前版本目录 + Common + 根目录」，绝不会加载 `1.6/`。**
所以这 4 条**不需要任何修改**。

## 8. 1.6 向下兼容复核（三个新补丁逐个过）

用户要求「旧版本游戏环境（1.6 及以下）也能跑」。本轮新增/改动的三项都依赖引擎方法，
所以逐个在 **1.6.4871 的 Assembly-CSharp** 里反编译核对。

### 8.1 【54】`Verse.Game.FillComponents` —— 1.6 与 1.7 **逐字相同**

1.6.4871 反编译原文：

```csharp
private void FillComponents()
{
    components.RemoveAll((GameComponent component) => component == null);
    foreach (Type item2 in typeof(GameComponent).AllSubclassesNonAbstract())
    {
        if (GetComponent(item2) == null)
        {
            try
            {
                GameComponent item = (GameComponent)Activator.CreateInstance(item2, this);
                components.Add(item);
            }
            catch (Exception ex)
            {
                Log.Error("Could not instantiate a GameComponent of type " + item2?.ToString() + ": " + ex);
            }
        }
    }
}
```

⇒ 两个关键前提在 1.6 也成立：

| 前提 | 1.6 | 1.7 |
|---|---|---|
| 第一行就 `components.RemoveAll(…)` ⇒ Prefix 里访问 `components` 安全 | ✅ | ✅ |
| 循环前有 `if (GetComponent(item2) == null)` ⇒ Prefix 先加进去就会被跳过 | ✅ | ✅ |

### 8.2 【66】`RavenRace…ChooseImplant`


### 8.3 【67】`Log.Error(string)`

本项只在消息含 `[TSIND Garage Doors QA` 时拦截，**与版本无关**。
